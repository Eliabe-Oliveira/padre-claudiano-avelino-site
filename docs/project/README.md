# Documentação do projeto

Este diretório reúne as decisões aprovadas que orientam o site Padre Claudiano Avelino:

- `semana-1-decisoes.md`: caráter, posicionamento, temas e limites gerais;
- `semana-2-arquitetura-editorial.md`: páginas, rotas, funções e tom editorial;
- `semana-3-design-system.md`: direção visual, paleta, tipografia e acessibilidade;
- `semana-4-arquitetura-tecnica.md`: stack, conteúdo, testes e restrições técnicas.

As decisões registradas não podem ser reinterpretadas ou ampliadas sem aprovação. Se uma solicitação contradizer uma decisão, a parte afetada deve ser interrompida até haver orientação explícita.

Cada etapa executada pelo Codex depende de autorização. Etapas futuras não devem ser iniciadas automaticamente.
