# Semana 3 — Design system

## Direção

A direção visual aprovada é **Palavra que respira**: editorial, contemplativa, contemporânea, humana, serena, acessível e centrada na leitura.

## Tipografia e experiência

- Source Serif 4 para títulos e leitura editorial;
- Inter para navegação, interface e metadados;
- fontes hospedadas localmente em etapa futura;
- fotografia humana e natural;
- espaços generosos, bordas discretas e conforto para leitura longa;
- movimento mínimo;
- prioridade para celular;
- acessibilidade orientada à WCAG 2.2 nível AA.

## Proibições visuais

Não usar marcas dos Paulinos ou da PAULUS, brasões, vitrais, pergaminhos, dourado ornamental, símbolos religiosos decorativos, estética institucional ou template religioso genérico.

O sistema visual não é implementado na Etapa 5.1; estas decisões são apenas registradas.

## Aplicação técnica de contraste

O terracota `#A8644A` não deve ser usado como cor de texto pequeno sobre os fundos claros aprovados, pois essa combinação não alcança 4,5:1. Rótulos e metadados pequenos usam o verde principal `#344E41`; o terracota permanece reservado a foco, linhas e acentos não textuais.
